# Cenit para GitHub Pages

Contenido adaptado para https://ManuelHerman.github.io/cenit2-/

Subir el contenido de esta carpeta a la raíz del repositorio cenit2-, conservando assets, img, categorias, marcas, productos y fonts. No subir la carpeta contenedora como una subcarpeta.

En Ajustes > Páginas, elegir Deploy from a branch, la rama principal y /(root). Guardar.

No incluye configuración Apache. Las fichas 3D y el contenido se conservan.
